Design — Section 3 : Stack & Design Patterns

Technologies retenues, patterns appliqués, structure des projets

🟢 Backend — Spring Boot 4 / Java 17
Librairies clés
Spring Security + JWT (auth)
Spring Data JPA + Hibernate
Flyway (migrations SQL)
Lombok (boilerplate)
io.jenetics:jpx (parsing GPX)
MapStruct (Entity ↔ DTO)
PostgreSQL driver / H2 (dev)
Design Patterns
Repository pattern — 1 interface JPA par entité
Service layer — logique métier isolée
DTO pattern — jamais d'entité JPA exposée directement
Strategy — calcul score RPG (extensible)
Facade — GpxProcessingService (parse + calcule stats)
Structure packages
com.adventurekm/
 ├── config/ (Security, CORS, Web)
 ├── controller/ (REST endpoints)
 ├── dto/ (request/response)
 ├── mapper/ (MapStruct)
 ├── model/ (entités JPA)
 ├── repository/ (interfaces JPA)
 ├── service/ (logique métier)
 └── exception/ (handlers globaux)
🔵 Frontend — Angular 21
Librairies clés
Leaflet + ngx-leaflet (carte GPX)
Chart.js + ng2-charts (profil élév.)
Angular Signals (state réactif)
Angular HTTP Client (API calls)
ngx-markdown (éditeur/rendu article)
CSS custom (pixel art theme)
Design Patterns
Smart / Dumb components — pages = smart, UI = dumb
Feature modules — lazy loading par route
Service + inject() — 1 service par domaine
Auth Guard — routes protégées par JWT
HTTP Interceptor — injection auto du token Bearer
Structure src/app/
src/app/
 ├── core/ (auth, guards, interceptors)
 ├── shared/ (header, footer, composants UI)
 ├── features/
 │   ├── home/
 │   ├── profile/
 │   ├── adventures/
 │   ├── leaderboard/
 │   └── admin/
 └── models/ (interfaces TypeScript)
🐳 Docker Compose — 4 services
nginx — reverse proxy + SSL (Certbot)

  /api → backend:8080
  /uploads → fichiers GPX+photos

backend — Spring Boot JAR

⚙ Fonctionnalités transverses
Auth JWT — login → access token + refresh token
Invitation — lien unique /register?token=XYZ
GPX parsing — upload → jpx → stats + GeoJSON
Photos — multipart, max 5 × 10Mo, resize auto
Score RPG — recalculé à chaque aventure publiée
Strava/Coros — OAuth2, volume annuel en lecture seule
Seed data — V2__seed.sql avec tes vraies aventures
Profils Spring — dev (H2) / prod (PostgreSQL)
